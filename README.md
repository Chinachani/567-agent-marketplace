# 567 Agent 官方能力市场 (567 Agent Marketplace)

本仓库是 [567 Agent](https://github.com/Chinachani/567-agent) 的官方能力市场源，提供即开即用、自动同步更新的 **AI 技能 (Skills)** 与 **模型上下文协议服务 (MCP)**。

## 特色

- 🎯 **开箱即用**：收录 70+ 个实用 AI Agent 技能（涵盖数据分析、设计、办公文档、音视频与代码开发），全部预置中文说明。
- 🔌 **精选 MCP**：收录 Anthropic 官方核心 MCP 服务（本地文件系统、网页抓取、Brave 搜索、GitHub 协同、Postgres/SQLite 数据库等）。
- 🚀 **自动化流**：配置 GitHub Actions 工作流，支持定时自动追踪上游技能库更新并由 567 API 自动翻译。

## 客户端接入方式

在 567 Agent 桌面端中，本仓库已作为默认官方市场源预置。在“能力中心”中即可直接浏览、一键安装和使用！
